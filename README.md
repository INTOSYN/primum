# Primum v2

Primum is a decision benchmark for cryo-EM re-refinement. The dataset includes starting models, refined candidates, higher-resolution reference structures, fixed scoring residue sets and evaluation results. It supports evaluation of refinement methods and selection rules through changes in packed-side-chain agreement relative to keeping the deposited model (no operation).

The Primum v2 dataset is hosted on [Hugging Face](https://huggingface.co/datasets/INTOSYN/primum)
